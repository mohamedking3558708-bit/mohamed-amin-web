إصلاح أداء موقع Mohamed Amin — بدون تغيير التصميم
====================================================

هذه الحزمة تعدّل مواضع محددة في نسخة المستودع الحالية بدل استبدال الموقع بنسخ HTML قديمة. لا تتصل الحزمة بحسابك ولا ترفع تغييرات إلى GitHub بنفسها.

طريقة الاستخدام على Windows
---------------------------
1) افتح المستودع الحالي:
   https://github.com/mohamedking3558708-bit/mohamed-amin-web
2) اضغط Code ثم Download ZIP، وفك ضغط المستودع في مجلد مستقل.
3) فك ضغط هذه الحزمة، وانسخ إلى المجلد نفسه الذي يحتوي على index.html وadmin.html:
   - Apply-Fixes.bat
   - apply_performance_fixes.py
   - المجلد _patch_templates كاملًا
4) انقر مرتين على Apply-Fixes.bat. تحتاج الحزمة إلى Python 3. إذا لم يكن مثبتًا، ثبّت Python 3 ثم أعد تشغيل الملف.
5) إذا ظهرت رسالة «تم تطبيق التعديلات بنجاح»، فستجد نسخًا احتياطية بجانب الملفات الأصلية تنتهي بـ .backup-التاريخ. اترك ملفات النسخ الاحتياطي ولا ترفعها إلى GitHub.
6) ارفع إلى GitHub الملفات التالية فقط، مع إبقاء مساراتها:
   - من جذر المستودع: index.html وadmin.html وwork.html وreviews.html
   - من functions/api/media/: الملف [key].js
7) اعمل Commit للتعديلات وانتظر اكتمال نشر Cloudflare Pages.

ما الذي يتغير؟
---------------
- شريط My Work يعرض صورًا مصغرة اختارها المستخدم فقط؛ لا يستخدم الفيديو نفسه كصورة معاينة.
- إضافة فيديو جديد تتطلب اختيار صورة مصغرة يدويًا. كما يمنع النشر إذا بقي أي فيديو قديم بلا صورة مصغرة.
- حركة الصور تتجه من اليسار إلى اليمين في حلقة متصلة، وتقيس عرض المجموعة الفعلي حتى لا تظهر فجوة عند إعادة البداية.
- فيديوهات الهيرو لا تبدأ جلب الملف قبل ظهور البطاقة، وتتوقف ويُفرّغ مصدرها عندما تخرج من الشاشة. صيغة الفيديو وجودته لا تتغيران.
- تحميل الخطوط يصبح مباشرًا بدل CSS @import، وتظهر الصفحة قبل اكتمال طلب تحديد الدولة.
- تضاف آلية كاش آمنة للملفات الصغيرة وطلبات Range؛ لا تُخزّن استجابة 206 على أنها الملف الكامل. تعمل الفائدة وفق توفر Cache API وبيئة Cloudflare، ويجب اختبارها بعد النشر.

ما الذي لا يتغير؟
-----------------
- لا تعديل للألوان أو blur أو glow أو backdrop-filter أو الظلال أو أحجام/زوايا البطاقات.
- لا تحويل WebM إلى MP4، ولا تغيير ترميز أو جودة الفيديو.
- لا تعديل على portfolio-data.json أو أسرار Cloudflare أو مفاتيح الوصول.

قبل إعادة النشر من لوحة التحكم
-----------------------------
الأعمال القديمة التي لا تملك thumbnailUrl لن تظهر في شريط My Work، وسيمنع النشر إلى أن تضيف صورة مصغرة لكل فيديو. افتح لوحة التحكم، ارفع صور المعاينات بنفسك، ثم انشر التعديلات.

إذا ظهرت رسالة «لم أجد موضع التعديل المتوقع»، فتوقف ولا تستبدل الملفات يدويًا. يعني ذلك أن نسخة المستودع تغيّرت عن الشكل المتوقع؛ أرسل نص الخطأ حتى نطابق التعديل مع النسخة الجديدة. لن يحفظ السكربت أي ملفات إذا فشل التحقق قبل مرحلة الكتابة.

اختبار سريع بعد النشر
---------------------
- افتح الرئيسية وراقب شريط الأعمال دورتين كاملتين: يجب ألا تختفي الصور أو يظهر فراغ عند تكرار الحلقة.
- افتح Network في أدوات المطور: شريط My Work يجب أن يطلب صور المعاينة، لا ملفات الفيديو.
- مرّر بعيدًا عن قسم الهيرو ثم ارجع إليه؛ يجب أن تتوقف فيديوهات الهيرو خارج الشاشة وتستأنف عند العودة.
- افتح فيديو من صفحة الأعمال وجرب التشغيل والتحريك إلى منتصف الفيديو.
